## Project Overview
This project is a **web and mobile application** designed to help **restaurants manage employees and optimize costs**. The platform enables efficient scheduling, payroll tracking, and other management functionalities, making it easier for restaurant owners to streamline operations while saving money.

## Technologies Used

- **React.js** - For building the web application.
- **React Native** - For the mobile application.
- **Firebase** - Backend services, including authentication, real-time database, and cloud functions.

## Features

- **Employee Management**: Add, update, and remove employees.
- **Shift Scheduling**: Organize and assign shifts efficiently.
- **Payroll Tracking**: Monitor wages and track employee payments.
- **Cost Optimization**: Analytics and insights to reduce unnecessary expenses.
- **Authentication**: Secure login system using Firebase Auth.
- **Real-time Data Sync**: Ensure consistency between web and mobile apps with Firebase.

## My Role

During this internship, I have been responsible for:
- Developing the **web application** using React.js.
- Building the **mobile application** with React Native.

## Impact

This application aims to improve restaurant efficiency by reducing administrative overhead, minimizing scheduling conflicts, and providing real-time insights to optimize labor costs.
